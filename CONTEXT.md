- **Store:** `ron-hajewski-shopify-portfolio.myshopify.com`
- **Tech Stack:** Shopify Plus, custom Liquid themes, JSON templates, Tailwind/CSS variables.

- **Workflow State:** Living workspace. Add new recurring instructions to `agents.md` as project scope expands.

## ICM Workspace Stage Routing

| Stage Directory | Scope & Responsibility |
